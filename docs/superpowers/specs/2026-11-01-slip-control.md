# Slip Control Design

Goal: determine whether the existing1.2 bounded-slowdown policy contributes to the user's wide-view performance/feel regression without changing graphics, simulation rules or synchronization.

The quiet Vita build currently discards existing slip state-change logs. Add only `GXV_SLIP_TRACE=1`, requiring the exact literal value1. Compile all new code only for `__vita__ && PORT_LOGGING`. Read this flag once inside the existing `SlipMax()` initialization. Emit one basic config row even when slip is disabled, then a basic state row only at the existing Changes()!=reported boundary. Keep the existing verbose log and its order. There are no new clocks, per-turn counters, cross-thread reads or periodic observers. Preserve errno around new summary logging; trace off must not access errno/TLS/clocks or produce summaries. Original slip configuration, decisions, callbacks, state and timing inputs remain unchanged.

Config fields: enabled, effective max_percent, trace=1. State fields: engaged, changes, pair_us, speed_percent, max_percent, lag_us. These are game-thread-owned existing values; pair/speed are estimates and lag does not certify a complete real-time offset. A trace1 config plus no engaged transition after its startup proves no engagement during a complete uninterrupted captured log, not that every scene is unaffected.

Tests use actual extracted production SlipMax/SlipWorkDone plus actual Slip class, injected clock/log boundaries only. Cover literal gates, off/on/max clamps, unchanged pacing decisions/state across trace0/1, positive engagement/leave/gap reset, no duplicate transitions, existing-log ordering, logger-modified errno, and inert non-Vita/logging-off compilation. Existing four full-module phase assembly guards must remain intact, not waived.

Physical: same verified binary, same Astro50-star stationary spawn/zoom1.0/native640/full-effects/AA0; trace1 common to both, only GXV_SLIP1/0 differs with MAX20 both. Exact prefix/complete-block/drop-first2/min-pair90-second controls, inspect captures. Rank actual turns, CPU/turn and shown cadence separately; no promise of improvement. If trace proves no engagement, do not call a small difference a policy win. Preserve logs, saves, HD pack, warm list, settings, no-sleep and rollback. Restore normal env and verify fresh foreground capture/integrity afterward. No public release, commit or push.

# Relay jobs of the 3.1 console session

Generated by `python3 tools/console31/make_jobs.py all` for [CONSOLE-SESSION-3.1.md](../CONSOLE-SESSION-3.1.md), which says when to run each one.

- `jobs/*.json`: relay jobs (a `batch` of steps in the relay's own format). Numbers 81xx, 82xx (section 3.14) and 8985, 8990.
- `staging/`: the env files (`env-<job>.txt`, each is the whole `env.txt` of its run), the scripted routes (`input-c31-*s.txt`) and `popin31-p1-presets.txt`. The owner's own `env-user.txt` is never here: it is made from the backup at the start of the session.
- `JOBS.txt`: one line per job with its estimated minutes and whether the owner's eyes are needed.

`python3 tools/console31/make_jobs.py install --relay <relay folder>` copies the staging files and the jobs into the relay; `queue --relay <relay folder> <job>...` moves chosen jobs into its inbox.

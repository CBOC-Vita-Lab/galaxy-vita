# so the post-attack plaza is reached at ~197 s instead of ~300 s.  Times are GAME seconds (59.94 frames each).
#   boot -> strap warnings -> title -> create file 1 (icon Mario) -> Play This File -> prologue storybook
#   -> Peach's letter -> Peach's Castle approach ("Gateway" path: walk down the festival path, spin, jump)
#   -> Bowser's airship attack (THP movie PrologueA.thp, ~97 s) -> the plaza after the attack (walk, spin, jump).
# Times are wall-clock seconds since process start (the game runs 60 fps = real time on this host, so also ~game seconds).
# Pointer coordinates -1..1 (right/down positive).  Needs a fresh save directory (run-desktop.sh makes one).

# The walk from the top of the path to the lake lookout is the one step that does not replay reliably (the stick is

# played with the stick.  Delete the next line to play the whole path by hand-tuned stick input instead.

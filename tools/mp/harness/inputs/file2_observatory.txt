# Title -> entry screen -> Single Player -> file select -> file 2 (Yoshi icon, 50 stars) -> "Play This File" -> the Observatory (Comet Observatory,
# AstroGalaxy). File 1 (Mario, 0 stars) would start the prologue (storybook), not the Observatory: use file 2.
# MARKS (11 Nov, harnessfix): the presses wait for the game's own log lines instead of fixed times since boot, which drifted by ~20 s between
# runs (a cold disk, a loaded machine) and fell out of step whenever a screen was added (the entry screen). `mark NAME /REGEX/ ~FALLBACK`
# declares a line to wait for; `NAME+<t>[-<t1>]:items` runs <t> game seconds after it was printed (all on the game clock, PETARI_GAME_CLOCK=1).
# FALLBACK = the absolute time of the old timeline (8 Nov, mp-int desktop build): used only with a game binary that has no mark support.
# The original all-absolute timeline is kept as file2_observatory_timed.txt.
mark title /boot: the title screen has appeared/ ~22
mark entry /entry: screen shown/ ~32
mark single /entry: chose single/ ~35.2
title+8-8.5:A|B           # (old 30 s) A+B on the title
entry+3-3.2:A             # (old 35 s) entry screen: Single Player (its cursor starts there on a fresh mp.cfg)
single+15-23:PX=0.25|PY=0.3   # (old 50-58 s) pointer on file 2 (screen 400,310 of 640x456; pointer -1..1, y down)
single+18-18.2:A          # (old 53 s)
single+31-39:PX=0.52|PY=0.78  # (old 66-74 s) pointer on "Play This File" (485,405)
single+34-34.2:A          # (old 69 s)
